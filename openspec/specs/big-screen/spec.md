# big-screen Specification

## Purpose

提供不需登入、適合教室投影的活動唯讀畫面，並以階段專用的伺服器視圖限制可揭露的提交資料。

## Requirements

### Requirement: 大螢幕活動頁與階段畫面
系統 SHALL 提供 `/screen` 唯讀頁面，顯示目前唯一活動的狀態，並依階段呈現符合投影需求的資訊。

#### Scenario: 沒有進行中的活動
- **WHEN** 使用者開啟大螢幕頁且系統沒有活動
- **THEN** 頁面顯示「目前沒有進行中的活動」

#### Scenario: 準備中顯示活動摘要
- **WHEN** 目前活動處於準備中
- **THEN** 頁面以大字顯示活動代碼、組數與排名規則文字，顯示「等待老師開始」，並以階段徽章標示準備中

#### Scenario: 搶答中只顯示各題送出組數
- **WHEN** 目前活動處於搶答中
- **THEN** 頁面逐題顯示「已送出 n／總組數 組」及搶答中階段徽章，不顯示倒數、答案、送出組別、順位或成敗資訊

#### Scenario: 搶答期間送出後數字即時更新
- **WHEN** 任一組在搶答中成功送出某題
- **THEN** 大螢幕即時更新該題已送出組數，且畫面與其伺服器視圖仍不包含送出組別、答案、順位或成敗資訊

#### Scenario: 已結束顯示成功組答案與其他組順位
- **WHEN** 目前活動已結束且該題有成功組
- **THEN** 頁面按題目及小題列出成功組與其答案；其他曾送出的組只顯示組名與原始順位，不顯示其答案，並以階段徽章標示已結束

#### Scenario: 已結束且沒有成功組
- **WHEN** 目前活動已結束且該題沒有成功組
- **THEN** 頁面顯示該題的原因句，若沒有任何組別送出則顯示「沒有組別送出」

#### Scenario: 終端輸出大螢幕網址
- **WHEN** 伺服器啟動並印出服務網址
- **THEN** 終端資訊一併印出大螢幕網址 `/screen`

### Requirement: 大螢幕專用伺服器視圖
系統 SHALL 以獨立 `screen` 角色提供專用白名單視圖；視圖只含大螢幕所需欄位，且內容 SHALL 依活動階段限制。

#### Scenario: 搶答中的 HTTP 與 Socket 視圖不含提交明細
- **WHEN** 大螢幕以 HTTP 取得狀態，或以 `screen` 角色透過 Socket 初次連線、查詢、重連或接收更新，且活動處於搶答中
- **THEN** 視圖只含活動摘要、題目識別及每題已送出數與總組數，不含任何答案、組別提交明細、組名、順位或成敗欄位

#### Scenario: 已結束視圖才提供結果
- **WHEN** 大螢幕以 HTTP 或 `screen` 角色透過 Socket 取得已結束活動視圖
- **THEN** 視圖可包含每題成功組名稱與小題答案、其他已送出組名稱及原始順位、跳過原因或無成功組原因，且其他組答案不得出現

#### Scenario: 大螢幕連線不能執行狀態變更
- **WHEN** `screen` 角色連線送出建立、開始、結束、設定或提交等任何改變活動狀態的事件
- **THEN** 伺服器拒絕該事件，且活動階段、設定及作答資料維持不變

#### Scenario: 公開 HTTP 回應使用階段白名單
- **WHEN** 未登入使用者透過大螢幕頁面或其狀態 HTTP 端點讀取活動
- **THEN** HTTP 回應只包含對應階段允許的大螢幕視圖，不包含老師控制資料或學生身分資料

### Requirement: 大螢幕投影視覺
大螢幕頁 SHALL 沿用深色介面視覺，使用適合投影的加大字級與清晰階段徽章。

#### Scenario: 大螢幕顯示投影版面
- **WHEN** 使用者在大螢幕頁檢視任一活動階段
- **THEN** 頁面使用深色樣式、加大主要文字並清楚顯示目前階段徽章
