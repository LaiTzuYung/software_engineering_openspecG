建立活動（純速度），第 1 組答第 1 題（A1、A2），第 2 組答第 3 題（D3），結束活動。全程使用同一個活動。

以下由自動測試涵蓋（`npm test` 162 項通過）：
- 第二次回寫才新增寫入的格子，也在第一次被寫入前記錄原值並正確還原。
- 還原預覽後、確認前試算表被修改時中止，要求重新預覽；還原後重讀驗證，與原值不符的格子列為失敗。
- 原值紀錄存於本機 `data/`，伺服器重新啟動後仍可讀取；舊版單次備份檔可讀取，格式錯誤的備份略過。
- 標記模式（`{{答}}`）還原時寫回含標記的原文。
- Q7：題組小題的標籤格右側沒有可用作答格、作答格退回標籤格時，回寫寫成「（1）答案」，半形標籤寫成「(1)答案」；同一格再次回寫為「（1）第二答案」，不累加舊答案；還原時寫回原標籤。修正前此情況只寫入答案，會覆蓋標籤（T1～T6 皆無此版面，由規劃階段檢查程式時發現）。
