## 發現問題

1. **搶答中老師表格不會即時更新，要重新整理頁面才看得到提交。**（已修正）
   - 現象：學生送出後，老師頁的「即時作答／結果」仍顯示「尚未送出」；重新整理或按結束後才出現資料。違反 R4（搶答中即時看到作答狀況）。
   - 調查：Chrome DevTools Network 的 WS 篩選為 0 個請求，Console 無錯誤，確認老師頁根本沒有建立 Socket.IO 連線。
   - 原因：本 change 第 3、4 章改寫老師頁 `show()` 時，移除了老師頁的 Socket 初始化與 `activity:teacher-view` 事件註冊（以 git 歷史比對 `54eb411` 與 `ae4b83e` 確認）。伺服器端的推播本身正常。
   - 修正：恢復老師頁 Socket 連線（使用登入時保存的 PIN、註冊老師視圖事件、自動重連）；統一 HTTP 與 Socket 的老師視圖產生函式並加測試確認欄位一致；頁面測試檢查老師連線與事件註冊。逐項比對 ui-polish 版本，確認其他老師與學生頁的事件處理沒有遺漏。修正後重測通過（第 4 列）。
