# Proposal

## Why

目前老師與學生頁以基本樣式呈現，階段、送出狀態和成功結果在教室投影或錄影時不夠醒目。統一深色主題下的版面層次與狀態視覺，可讓老師更容易操作和講解，也讓學生更快辨識目前狀態。

## What Changes

- 改善老師與學生頁的深色視覺：置中限寬、卡片、統一間距與清楚字級層次，並提高基礎字級。
- 以一致的徽章呈現準備中、搶答中與已結束；以主色、危險色、次要色及明顯停用狀態區分按鈕用途。
- 強化老師表格中的成功組、順位、答案與固定表頭，並為回寫預覽狀態及學生端題目、送出確認、成功結果與訊息提供清楚色彩對比。
- 放大老師頁活動代碼，方便口頭告知。
- 僅調整 CSS 與 HTML 結構／class；保留所有既有元素 ID、按鈕文字及測試依賴的選擇器，不改變 JavaScript 行為、API、Socket 事件或資料結構。
- 維持純 HTML/CSS/JS 與離線可用，不加入前端框架或外部 CDN；學生頁 R9 白名單資料不變，既有 97 個自動測試須全數通過。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `live-buzzer`: 新增階段徽章與成功結果的視覺可辨識要求。

## Impact

- 主要影響 `src/live-buzzer/pages.ts` 中老師與學生頁的 HTML/CSS 結構及樣式。
- 既有 `live-buzzer` 視覺呈現規格新增一項 requirement；不變更 API、Socket.IO、伺服器資料或學生 R9 白名單。
- 驗收包含 `npm test` 全數通過，以及老師頁與學生頁於三個活動階段的人工截圖檢查。
