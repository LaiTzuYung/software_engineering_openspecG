# Design

## Context

現有 `parseGuidedNotes` 先找動態表頭，再依題號列、作答範圍及 Q7 標籤推定作答格；匯入題目集保存題號、小題及作答格座標。回寫預覽服務重新讀取來源並解析，再比對題號／小題／作答格位置；預覽保存目前值，確認時重讀以防預覽後來源改變，成功寫入前備份原值與寫入值。細節見 proposal 與兩份 delta spec。

## Goals / Non-Goals

**Goals:**

- 以一個全表解析模式選擇擴充作答格定位，並保證未使用標記時保持目前結果。
- 保存標記模式及匯入時定位／標記模板，讓解析、預覽、確認、重複回寫和還原共享同一份來源結構資料。
- 遵守 Q11：每次預覽及確認仍重新讀取來源並檢查題目／小題／座標；標記消失時僅在定位與匯入快照一致時沿用原作答格。

**Non-Goals:**

- 不改題號、題目敘述、Q7 表頭模式、答案排名或成功組判定。
- 不在沒有標記的工作表中推斷或改變既有作答範圍，也不把標記模式下未標記題目自動回退為表頭定位。
- 不改 RAW 值寫入方式、服務帳戶權限模型或備份保存位置。

## Decisions

### 1. 先決定整份工作表的定位模式，再解析題目

找到表頭後，掃描表頭以下所有儲存格。以 Unicode NFKC 將全形括號等字元正規化，並在標記 token 內忽略空白；偵測到至少一個 `{{答}}` 才切到標記模式。比對必須保留原始儲存格字串及 token 的原始範圍，因為預覽需要顯示原文，回寫也要保留標記外文字。整份表不含 token 時直接走既有表頭解析路徑，不對既有行為作重寫。

標記可以位於任何表頭下儲存格。標記模式下以標記格建立小題，依 Q3 將列歸到本列題號或最近有效題號；每題按 row、column 排序。標記格前綴的「（n）」優先提供小題號；否則讀同列 Q7 標籤格，仍沒有時沿用現有順序編號。空白檢查從原值移除標記 token 後判斷，因此單獨標記視為空白；標記外仍有文字則視為有內容。

沒有可歸屬題號的標記不成為作答格，產生各自帶座標的警告；任何解析到但沒有標記小題的題目亦產生警告，位置使用題號格。預覽結果增加定位方式標籤。T6 從 T2 複製，六個作答格只加標記，以既有 T2 預期作為逐項比較的 oracle；標記偵測另外以全形與空白變體覆蓋。

### 2. 將定位快照與標記替換模板保存在匯入題目集

匯入確認時除既有題目／小題座標外，保存定位模式及來源結構快照；標記模式另外保存每一作答格的原始標記樣式與標記前後字串模板。舊題目集缺少這些欄位時視為表頭模式，以維持舊資料相容。

解析器對單一儲存格中的每個有效標記位置都建立替換片段；規劃預設同一格出現多個標記時全部替換為同一個答案。這能保留例如「答：{{答}}」的前綴，也讓已成功替換過的格子在後續回寫中仍可用同一匯入模板產生完整預計值，而不把前一次答案當成新的模板。

### 3. 標記移除後仍以 Q11 快照比對，不以標記缺席直接判定失敗

每次預覽與確認仍讀取 Google 試算表。標記模式不以目前標記解析結果或表頭解析結果重新推定題組結構，而是逐項檢查匯入快照：題號格必須仍位於匯入時座標且原始值相同；每個小題的作答格固定使用匯入座標，格內內容必須仍含答案標記，或符合標記模板前綴、任意答案內容及後綴。任何題號格或作答格不符時中止，指出題號及儲存格位置並回覆「請先還原再回寫」。一致時沿用匯入的小題與作答格快照；預覽目前內容顯示來源原值，預計值以保存模板替換答案。這允許答案相同時略過，也允許再次寫入不同答案。非標記模式維持現行重新解析與結構比對流程。

預覽「目前內容」永遠顯示重新讀取的原始儲存格值；「預計值」以保存模板替換答案。確認仍以預覽時原值做樂觀鎖定，寫入模板替換後的完整字串，使用 RAW。成功回寫備份保存當時原值（首次回寫時含標記）、預計寫入值與座標；還原重新讀取並確認目前值仍等於備份寫入值後，以 RAW 寫回備份原文。這也允許還原已不含標記的工作表，而不依賴再偵測標記。

### 4. 人工 T6 採專用副本，避免破壞 T2

建立名為「T6 標記測試」的 Google 試算表副本：從 T2 複製並在 H5、H6、H8、H9、G11、G13 放入 `{{答}}`，共享給服務帳戶並設為編輯者。逐項確認預覽定位、題型／標籤、回寫後內容、回寫後再次預覽及從備份還原的標記原文。前綴模板「答：{{答}}」及回寫後再次預覽由自動測試涵蓋（`T6 的 G11 前綴變體預覽原文與保留前綴的完整預計值`）；自動 fixture 的基準比較仍保留 G11 為單獨標記。

## Risks / Trade-offs

- [Unicode 正規化可能誤辨識不同字元組合] → 只在標記辨識範圍套用全半形正規化與空白忽略；原始內容及其他文字不正規化。
- [已有表格內容可能被誤判為可寫答案] → 標記模式只採標記格為作答格；其他未標記題目以帶座標警告提示，供老師在確認匯入前修正。
- [重複回寫可能失去原模板] → 模板隨匯入定位保存，不從已被替換的目前內容猜回前綴；每次仍以當前格值作預覽及確認比對。
- [Q11 fallback 可能遇到版面變動] → 只在題號／小題／座標與匯入快照相符時沿用標記定位；不符即停止，不寫入。

## Migration Plan

1. 先新增解析模式、定位快照與模板資料型別，舊題目集缺省採表頭模式。
2. 加入標記解析、T6 fixture 及全形／空白、警告、預覽相容測試。
3. 串接預覽替換值、RAW 確認、Q11 標記消失 fallback 與原文還原測試。
4. 依 tasks 第 4 章建立並操作「T6 標記測試」Google 試算表。
5. 回退時將既有資料一律視為表頭模式並移除標記模式入口；既有無標記來源不需轉換。
