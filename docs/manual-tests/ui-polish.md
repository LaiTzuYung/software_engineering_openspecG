## 實作過程發現的問題

1. **老師登入頁未套用新樣式。**（已修正）第一版樣式只套用到老師控制台與學生頁，登入頁仍為瀏覽器預設樣式；補上置中卡片樣式。
2. **學生結束畫面的成功組結果被移除。**（提交前已修正）新增「本組答案」時，需求描述被理解為結束後也不得顯示任何他組資訊，導致每題成功組與答案不再顯示，違反「學生在搶答結束後檢視結果」。在審查 Codex 回報時發現，提交前恢復原行為，並修正 proposal／spec／design 的例外敘述與測試斷言。
3. **學生結束畫面題目重複列出兩次。**（已修正）恢復結果後，「本組作答狀況」與「活動結果」各列一次 4 題且無標題；改為每題一張卡片合併顯示（見第 8 列）。
