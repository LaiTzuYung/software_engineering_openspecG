# Spec Delta

## ADDED Requirements

### Requirement: 接受提交時記錄伺服器時間
系統 SHALL 在伺服器接受一筆提交時記錄 ISO 8601 時間，並將其與提交及其所有小題答案關聯。

#### Scenario: 記錄單題送出時間
- **WHEN** 伺服器接受一組對單題的有效答案
- **THEN** 提交紀錄包含伺服器產生的 ISO 8601 送出時間

#### Scenario: 題組小題共用送出時間
- **WHEN** 伺服器接受一組完整題組答案
- **THEN** 該筆提交的所有小題答案使用同一個伺服器 ISO 8601 送出時間

#### Scenario: 不採用客戶端時間
- **WHEN** 學生提交資料包含客戶端時間或系統時鐘不同
- **THEN** 提交紀錄仍使用伺服器接受該提交時產生的時間
