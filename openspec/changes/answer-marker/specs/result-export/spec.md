# Spec Delta

## MODIFIED Requirements

### Requirement: 回寫前重新定位並驗證表格結構
系統 SHALL 在回寫預覽及確認回寫時讀取原 Google 試算表，依匯入解析規則重新定位作答格，並以題號與小題號比對匯入結構及作答格座標。對於已完成標記替換、因而不再含 `{{答}}` 的工作表，系統 SHALL 以匯入時保存的題號與作答格座標核對目前定位；一致時可沿用匯入定位，不一致時中止並說明「請先還原再回寫」。

#### Scenario: 結構一致時產生預覽
- **WHEN** 老師為已結束活動要求回寫預覽，且重新解析結果的題號、小題及作答格位置與匯入資料相符
- **THEN** 系統為每個有成功組答案的小題列出工作表與 A1 座標、目前內容、預計寫入值及狀態

#### Scenario: 題數或題號不同時中止
- **WHEN** 重新讀取後題目新增、刪除、重複或題號改變
- **THEN** 系統中止回寫並指出結構差異，且不寫入任何儲存格

#### Scenario: 題組小題或作答格位置不同時中止
- **WHEN** 重新讀取後小題新增、刪除、重新分類，或任一作答格座標與匯入時不同
- **THEN** 系統中止回寫並指出差異，且不寫入任何儲存格

#### Scenario: 已替換標記但匯入座標仍一致
- **WHEN** 先前回寫已將標記替換為答案，重新讀取後標記不存在，且目前題號與作答格位置和匯入時保存的結構一致
- **THEN** 系統以保存的匯入定位建立或確認預覽，不因標記已被替換而誤判結構改變

#### Scenario: 標記消失且作答格座標改變
- **WHEN** 先前回寫已將標記替換為答案，但重新讀取後題號或作答格座標與匯入時保存的結構不同
- **THEN** 系統停止回寫、不寫入任何儲存格，並說明「請先還原再回寫」

#### Scenario: 讀取權限不足
- **WHEN** 系統讀取試算表時服務帳戶沒有檢視權限
- **THEN** 系統顯示明確的讀取權限錯誤，說明需將試算表共享給服務帳戶並至少設為檢視者，且不進行寫入

#### Scenario: 預覽後試算表改變
- **WHEN** 老師確認回寫時重新讀取、定位或目標格內容與預覽時不一致
- **THEN** 系統中止該次回寫並要求重新產生預覽，且不寫入任何儲存格

### Requirement: 預覽確認後只回寫成功組答案
系統 SHALL 讓老師先檢視每個目標作答格，再於確認時將成功組答案寫入原 Google 試算表；對含有 `{{答}}` 的作答格，預覽 SHALL 顯示含標記的目前原文及以答案取代所有標記後的完整預計值，確認時以 RAW 值寫入該完整值；確認代表老師同意覆蓋預覽所列的不同內容。

#### Scenario: 老師確認含覆蓋的回寫
- **WHEN** 老師確認一份仍與試算表一致的回寫預覽
- **THEN** 系統只將答案寫入預覽中的作答格，且使用 RAW 值輸入

#### Scenario: 標記格預覽保留原文並呈現完整預計值
- **WHEN** 成功組答案為 `D3` 且作答格目前內容為「答：{{答}}」
- **THEN** 回寫預覽的目前內容顯示「答：{{答}}」，預計值顯示「答：D3」

#### Scenario: 標記替換保留前後文字
- **WHEN** 老師確認作答格內容為「答：{{答}}」的回寫預覽
- **THEN** 系統以 RAW 寫入「答：D3」；只有 `{{答}}` 時預計值及寫入值均為答案本身

#### Scenario: 小題標籤保持不變
- **WHEN** 成功組提交題組答案且解析結果包含標籤格與其右側作答格
- **THEN** 系統將答案寫入作答格，並保持標籤格及題目儲存格原值不變

#### Scenario: 沒有成功組的題目
- **WHEN** 活動結束時某題沒有任何成功組
- **THEN** 該題所有作答格保持原狀且不列入寫入請求

#### Scenario: XLSX 匯入來源要求回寫
- **WHEN** 題目集來源是 XLSX 而非 Google 試算表
- **THEN** 系統不提供試算表回寫功能，且不嘗試建立線上試算表目標

#### Scenario: 服務帳戶沒有編輯權限
- **WHEN** 老師確認回寫，但服務帳戶對該試算表只有檢視權限
- **THEN** 系統顯示明確的中文錯誤，說明須將試算表共用給服務帳戶並設為編輯者，不寫入任何儲存格，該次備份標記為失敗且不視為「最近一次成功回寫」

### Requirement: 保存每次回寫備份並可還原
系統 SHALL 在每次寫入前將每個目標格原值及本次寫入值保存於本機 `data/` 下的獨立 JSON 備份，並提供還原最近一次回寫的操作；標記模式備份 SHALL 保存含標記的原始內容，以供還原。

#### Scenario: 寫入前建立本機備份
- **WHEN** 老師確認回寫且目標格仍與預覽一致
- **THEN** 系統先保存本次所有目標格的原值、寫入值、座標及試算表識別資訊，再呼叫 Sheets API 寫入

#### Scenario: 還原最近一次回寫
- **WHEN** 老師要求還原最近一次成功回寫
- **THEN** 系統逐格讀取並比較目前內容與該次寫入值，只還原相同的格子，並列出已還原與因內容不同而跳過的格子

#### Scenario: 還原時格子已被再次修改
- **WHEN** 最近一次回寫的目標格目前內容不等於該次寫入值
- **THEN** 系統跳過該格，不覆蓋目前內容，並在還原結果中列出座標與跳過原因

#### Scenario: 還原標記格的原始文字
- **WHEN** 最近一次成功回寫曾將「答：{{答}}」寫成「答：D3」，且格子目前仍等於該次寫入值
- **THEN** 系統從備份還原「答：{{答}}」原文；若格子內容已不同則依既有保護規則跳過，不覆蓋後續修改
