# Spec Delta

## ADDED Requirements

### Requirement: 以顯式標記定位 Guided Notes 作答格
系統 SHALL 在表頭以下掃描顯式答案標記，並於標記模式以標記格作為作答格；未找到標記時 SHALL 完全沿用既有表頭模式。

#### Scenario: 標記正規化並切換整份試算表模式
- **WHEN** 表頭以下任一格含有經全形半形正規化並移除空白後可辨識的 `{{答}}`，包括 `{{ 答 }}` 與 `｛｛答｝｝`
- **THEN** 整份試算表使用標記模式，所有含標記的格子成為作答格；標記前後非標記文字及來源儲存格內容保持原樣供後續預覽與回寫使用

#### Scenario: 標記格題號歸屬及小題順序
- **WHEN** 一題有一個以上標記格，標記列可能沒有題號
- **THEN** 每個標記歸屬於該列題號，或依 Q3 歸屬上方最近的有效題號；同一題標記依列再依欄排序為小題，一個標記為單題、兩個以上為題組

#### Scenario: 標記格小題標籤
- **WHEN** 標記格開頭含有「（n）」小題標籤，或該列沒有此標籤
- **THEN** 系統優先以標記格開頭的 n 作為小題編號；否則依 Q7 使用同列作答範圍第一格的標籤格，並沿用既有預設小題編號規則

#### Scenario: 標記不算作答格既有答案
- **WHEN** 系統檢查含標記作答格是否已有內容
- **THEN** 標記文字本身不算既有答案；只有 `{{答}}` 的格子視為空白，標記外的其他文字仍視為內容

#### Scenario: 標記模式警告及儲存格位置
- **WHEN** 標記位於第一個有效題號之前、位於無法辨識題號的題目範圍，或一個已解析題目沒有任何標記
- **THEN** 預覽對各情況顯示警告並指出標記格或該題題號格的工作表及儲存格位置，不將無法歸屬的標記當成有效作答格

#### Scenario: 標記版 T6 與 T2 解析結果相同
- **WHEN** 系統解析 T6（由 T2 製作，並在 H5、H6、H8、H9、G11、G13 放入 `{{答}}`）
- **THEN** 解析結果與 T2 完全相同：4 題；第 1、2 題為各 2 小題的題組，第 3、4 題為單題；作答格依序為 H5、H6、H8、H9、G11、G13；題組標籤及小題編號相同

#### Scenario: 無標記時既有 fixture 完全相容
- **WHEN** 系統解析沒有任何標記的 T1、T2、T3、T4 或兩份 T5 fixture
- **THEN** 使用既有表頭模式，題數、題型、作答格、標籤、警告及錯誤結果均與變更前完全相同

### Requirement: 匯入預覽顯示作答格定位方式
系統 SHALL 在匯入預覽中明確指出本次解析採用的作答格定位方式。

#### Scenario: 顯示標記模式摘要
- **WHEN** 表頭以下存在有效的 `{{答}}` 標記並採用標記模式
- **THEN** 預覽摘要顯示「定位方式：{{答}} 標記」

#### Scenario: 顯示既有表頭模式摘要
- **WHEN** 表頭以下沒有任何有效的 `{{答}}` 標記
- **THEN** 預覽摘要指出採用既有表頭定位方式，且不影響既有題目預覽內容
