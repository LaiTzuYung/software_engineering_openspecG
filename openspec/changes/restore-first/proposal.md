# Proposal

## Why

目前每次回寫都各自記錄當下原值，還原最近一次回寫無法把多次回寫的格子帶回第一次匯出前；還原時遇到手動修改也只會略過，老師無法透過預覽確認後安全地統一復原。題組答案退回標籤格時，現行回寫亦未保留小題標籤。

## What Changes

- 將每個活動、每個目標格的原值固定為該活動首次寫入前的內容；後續回寫新增格子時才為該格首次記錄原值。紀錄持續保存於本機 `data/`，活動重複回寫及伺服器重啟後均可沿用。
- 將還原改成預覽與確認兩階段。預覽列出 A1、目前內容、首次回寫前原值及「將還原」／「已被手動修改」狀態；確認前重新讀表，比對預覽快照，不一致則中止並要求重預覽。確認會還原全部列出的格子，包括手動修改者，並重讀驗證、逐格回報失敗。
- 保留原還原按鈕的既有 `id`，文字改為「還原到第一次回寫前」，並以新流程取代立即還原最近一次回寫。
- 依 Q7，在標籤格沒有右側可用作答格時，將答案接在原標籤文字後寫入同一格；還原回該標籤格的原文。既有 Q7 邊界行為須補測試。
- 更新 `result-export` 行為規格與人工測試步驟，涵蓋兩次回寫、手動修改、確認前變動、伺服器重啟及 Q7 標籤格。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `result-export`: 固定活動逐格原值、兩段式預覽確認還原、確認時快照比對及結果驗證；修正標籤格退回時的回寫內容與還原行為。

## Impact

- 主要涉及 `src/guided-notes/spreadsheet-export-validation.ts`、`src/live-buzzer/http-server.ts`、`src/live-buzzer/pages.ts` 及 `tests/spreadsheet-export-validation.test.ts`、HTTP／頁面測試；備份資料位於 `data/spreadsheet-export-backups/`。
- 增加還原預覽與確認 API 流程；既有還原路由可調整為相容入口或配合新增確認端點，但不改變原按鈕 `id`。
- 驗收遵循使用者提供的共同需求基準 v0.7 Q12、Q7 條文。此工作目錄中的 `docs/共同需求基準.md` 目前標示草稿 v0.4；該版 Q7 已涵蓋「無右側格時以標籤格作答」，但明確的原標籤格式保留寫法以本提案所列 v0.7 驗收條件為準。
