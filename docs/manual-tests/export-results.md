## 發現問題

1. **題目集選單無法分辨，且舊版匯入被誤稱為 XLSX 來源。**（已修正）
   - 現象：建立活動的下拉選單每一項都顯示「學習單（4 題）」；選到第 1 章之前匯入的題目集時，結果匯出區塊顯示「題目集來源為 XLSX」並停用回寫，但實際來源是 Google 試算表。
   - 原因：舊題目集沒有來源欄位，介面一律當作 XLSX；選單只顯示工作表名稱與題數。
   - 修正：選單改顯示「工作表名稱（題數）｜來源｜匯入時間」，依匯入時間新到舊排序並預設選最新；舊版匯入另外提示「此題目集匯入時未記錄試算表來源，請重新匯入 Google 試算表後再建立活動」（tasks 6.3）。

2. **還原時，原本空白的格子沒有被清空，結果卻回報「已還原」。**（已修正）
   - 現象：見 7.4 第一次測試。
   - 原因：備份把空白原值存為 `null`，還原時把 `null` 送進 Sheets API `values.batchUpdate`；API 對 `null` 的處理是不更動該格，因此實際沒有清空。原流程也沒有在還原後重讀確認。自動測試使用 mock，未能發現。
   - 修正：空白原值改以空字串 `""` 寫入；還原後重新讀取每一格，實際值符合原值才列為「已還原」，否則列為失敗並顯示實際值與預期值；新增 2 個測試（tasks 4.3）。修正後重測通過。
