# Guided Notes 格狀資料解析器

此文件說明第 1 階段完成的來源無關資料模型與解析器。解析器只接收工作表名稱、稀疏格值與合併範圍；資料來源讀取由後續轉接器負責。

## 資料模型

- `GridSheet.name` 是工作表名稱。
- `GridSheet.rows` 以陣列索引對應一基列號；每列的陣列索引對應一基欄號，未提供的值視為空白。
- `GridSheet.mergedRanges` 使用一基、起訖皆包含的座標。轉接器須先把來源座標轉成此格式。
- 儲存格值支援文字、數值、布林值與空值。

解析輸出包含正規化題號、題目敘述、單題／題組分類、每個小題的標籤格與作答格位置，以及警告。座標保留工作表名稱、列與欄，可用 A1 座標工具轉換欄號。

## 定位與解析規則

解析器掃描工作表前 20 列，尋找同時包含「題號」及「作答」的表頭；表頭關鍵字可由呼叫端設定。比對前會移除空白並套用 Unicode NFKC 正規化。題號欄、可選題目欄與作答範圍皆由該表頭及其合併範圍推得，不依賴範本的固定欄列。

表頭以下逐列解析：題號格有值時建立新題；題號格為空但題目或作答範圍有內容時，延續上一題建立小題；整列在相關題目與作答欄皆空白時略過。上下合併的題號格，其下方列延續為同一題。題號可接受數值整數、`1`、`1.`、`１`、`Q1`、`第1題` 等形式；無法解析或題號重複時整份解析失敗，錯誤包含格座標。

作答表頭合併範圍提供作答欄界線。若範圍第一欄是「（n）」標籤，解析器記錄小題編號 n，並在標籤右側範圍內尋找第一個空白作答格；候選格皆有內容時採第一格並附警告，右側沒有候選格時回退到標籤格。題組某列沒有標籤時，解析器依該題已解析的小題順序指派下一個編號（例如前一小題為 1，未標記的小題編為 2）。未標記的作答欄採用第一欄；作答格若屬合併範圍則記錄其左上角。同一題若多個小題定位到相同作答格，保留首次定位並附重複作答格警告。

表頭以下任何儲存格含有正規化後的 `{{答}}` 時，整份工作表改用標記定位：只有標記格會成為作答格，標記可忽略全形／半形差異及 token 內空白。標記格依本列或上方最近的有效題號歸屬，同題按列、欄排序；標記格開頭的「（n）」優先作為小題編號，否則使用同列標籤或順序編號。標記文字本身視為空白，標記外文字保留作為答案前綴或後綴。首個有效題號前、無法歸屬題號下的標記，以及沒有標記的小題會附上儲存格位置警告。沒有標記時沿用既有表頭定位結果。

匯入題目集保存定位模式、題號／小題／作答格快照與標記替換模板。回寫預覽以答案替換模板內所有 token，保留其他文字，並顯示定位方式；Google Sheets 仍以 RAW 寫入完整字串。標記被取代後，回寫預覽會用既有表頭規則重新解析並比對快照，結構不符時要求先還原。備份保留標記原文，還原前會確認目前值仍等於上次寫入值。

解析器不呼叫 Google Sheets API 或讀取來源檔案。不同來源必須先轉成相同的格狀資料。XLSX 轉接器以 ExcelJS 4.4.0 讀取資料，將合併範圍轉成內部一基、起訖皆包含的列欄座標；合併子格值不複製，只保留左上角儲存格值。Google Sheets 轉接器以官方 `googleapis` 189.0.0 讀取線上試算表，並以 `UNFORMATTED_VALUE` 取得數值；Google API 的 0 起算、結束不含合併範圍會轉為同一內部座標慣例，合併子格值清空。

線上認證只從 `GOOGLE_SERVICE_ACCOUNT_KEY_FILE` 讀取 repo 外 JSON 檔路徑，交由 Google Auth 載入。程式只取 auth library 提供的 `client_email` 作為權限錯誤訊息，不輸出或記錄憑證內容。自動測試以 mock 驗證，無需 Google 憑證或網路。

## 驗證

需要 Node.js 22。安裝開發相依後執行：

```sh
npm install
npm run typecheck
npm run test:unit
```

單元測試使用記憶體中的格狀資料，不連線 Google；`.xlsx` fixtures 的端對端驗收屬第 2 階段。

## 預覽、確認與 CLI

`GuidedNotesImportService` 接收 `ParseResult`，不依賴 Google Sheets 或 ExcelJS。預覽包含題數、單題／題組分類、每個小題的標籤格與作答格位置及解析警告。建立前資料只保留在記憶體；呼叫確認後才寫入 `data/guided-notes/<id>.json`，並保留同一題目集於記憶體。自動測試以作業系統暫存目錄驗證確認前沒有檔案、確認後 JSON 與記憶體一致，測試完成會刪除暫存資料夾。

以 Google Sheets 網址執行 CLI 並預覽：

```sh
npm run import -- <Google 試算表網址>
```

CLI 顯示預覽後詢問是否確認；輸入 `y` 才會保存。`.xlsx` 路徑模式只用於離線測試，例如：

```sh
npm run import -- tests/fixtures/guided-notes/T1-single.xlsx
```

題目敘述有欄時擷取、沒有欄時留空；候選格已填時取第一格並附警告；標籤右側沒有可用格時退回標籤格。這些暫定行為及記憶體加 JSON 檔的儲存方式仍待與 SpecKit 組對齊。
