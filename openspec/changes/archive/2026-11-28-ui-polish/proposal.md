# Proposal

## Why

目前老師與學生頁以基本樣式呈現，階段、送出狀態和成功結果在教室投影或錄影時不夠醒目。統一深色主題下的版面層次與狀態視覺，可讓老師更容易操作和講解，也讓學生更快辨識目前狀態。

## What Changes

- 改善老師登入頁、老師控制台與學生頁的深色視覺：置中限寬、卡片、統一間距與清楚字級層次，並提高基礎字級；老師與學生主要內容使用相同最大寬度並水平置中。
- 以一致的徽章呈現準備中、搶答中與已結束；以主色、危險色、次要色及明顯停用狀態區分按鈕用途。
- 強化老師表格中的成功組、順位、答案與固定表頭，並為回寫預覽狀態及學生端題目、本組答案與訊息提供清楚色彩對比。
- 放大老師頁活動代碼，方便口頭告知。
- 將老師匯入預覽改為易讀摘要、警告清單與逐小題表格，並將原始 JSON 放在預設收合的「原始資料」區塊；保留確認匯入流程及預覽 API／資料結構。
- 放大老師頁「向學生顯示題目敘述」控制項的點擊範圍，保持既有 ID 與切換行為。
- 學生提交題目後可展開預設收合的「查看本組答案」，題組逐小題列出本組答案。
- **明確範圍例外（學生 R9 資料）**：為了讓學生核對本組提交，學生視圖新增只屬於該學生組別的本組答案欄位；該欄位於任何階段都只含本組答案。活動結束前學生視圖維持不含他組資料或結果；活動結束後每題成功組名稱與成功答案的 `results` 維持既有行為，除此以外不在本組答案欄位加入他組資料。此例外只增加本組答案欄位，不改變既有結果可見行為，也不更動 API 路由、Socket 事件名稱或資料儲存結構。
- 保留所有既有元素 ID、按鈕文字及測試依賴的選擇器；允許調整頁面顯示所需的 DOM 組裝與 class，不改變既有互動流程、API 路由或 Socket 事件名稱。
- 維持純 HTML/CSS/JS 與離線可用，不加入前端框架或外部 CDN；學生視圖採明確白名單，完整自動測試須全數通過。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `live-buzzer`: 新增階段徽章與成功結果的視覺可辨識要求。

## Impact

- 影響 `src/live-buzzer/pages.ts` 的樣式與顯示 DOM、`src/live-buzzer/views.ts` 的學生視圖白名單，以及對應的單元／HTTP／Socket 測試。
- `live-buzzer` delta 更新 R9 契約：新增的本組答案欄位只可含本組答案，並保留活動結束後既有的成功組名稱與成功答案結果；HTTP 路由與 Socket 事件名稱不變，學生視圖 payload 新增本組答案欄位。
- 驗收包含 `npm test` 全數通過，以及老師頁與學生頁於三個活動階段的人工截圖檢查。
