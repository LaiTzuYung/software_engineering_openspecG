# Spec Delta

## ADDED Requirements

### Requirement: 回寫預覽快照僅限目前伺服器工作階段
系統 SHALL 僅將待確認的回寫預覽與還原預覽快照保存在伺服器記憶體；伺服器重啟後 SHALL 要求老師重新產生預覽，且不得沿用重啟前的預覽識別碼執行寫入或還原。

#### Scenario: 重啟後重新建立回寫預覽
- **WHEN** 老師在重啟前已建立回寫預覽，伺服器隨後重啟
- **THEN** 舊預覽識別碼無效，老師須重新按「回寫預覽」取得新快照後才能確認回寫

#### Scenario: 重啟後重新建立還原預覽
- **WHEN** 老師在重啟前已建立還原預覽，伺服器隨後重啟
- **THEN** 舊預覽識別碼無效，老師須重新按「還原預覽」取得新快照後才能確認還原

#### Scenario: 老師頁說明預覽需重建
- **WHEN** 老師查看結果匯出區
- **THEN** 畫面說明活動資料會保存，而回寫預覽快照只存在記憶體且重啟後須重新預覽
