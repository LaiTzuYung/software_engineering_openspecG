已確認規則
使用流程
1. 老師輸入 Google 試算表網址，系統透過 Google Sheets API 直接讀取線上試算表，不下載成 .xlsx 離線處理。
2. 系統解析並列出題目，匯入預覽需顯示總題數、單題或題組、每個小題的作答格位置與警告。
3. 老師確認預覽後才建立題目集；發生錯誤時不建立題目集。
4. 題目一律為簡答題，只需題號；題目敘述可選擇性擷取。
定位與解析
- 題目範圍為 Q1～Q11。掃描前 20 列，尋找同時含「題號」與「作答」的表頭列；比對前去空白並統一全半形。
- 從表頭定位題號欄與「作答」欄位。作答範圍取「作答」表頭儲存格的涵蓋範圍；若表頭為合併儲存格，取完整合併範圍。
- 表頭下方逐列解析：題號欄有值時是新題；題號欄為空，或屬於上一題的同一合併儲存格且有內容時，是上一題的下一小題；整列空白則略過。
- 題號正規化接受數值 1.0，以及 1、`1.`、`１`、`Q1`、`第1題` 等表示法。
- 一題只有一個作答格時是單題；有兩個以上作答格時是題組。
- 作答範圍第一欄若有「（n）」內容，視為標籤格。作答格是同列、標籤右邊、仍在作答範圍內且不屬於標籤合併範圍的第一個空白格。標籤不修改。
- 若符合上述條件的空格都已填內容，取第一格並在預覽顯示警告。
- 若標籤右側沒有可用格（例如作答範圍只有一欄，或合併範圍涵蓋整個作答範圍），作答格就是標籤格；匯出寫成「（1）答案」。這是基準中的解析與回寫規則，本次匯入需求是否需要一併涵蓋該邊界情況，可列入 SpecKit 對齊。
- 合併作答格記錄左上角座標；每個小題記錄工作表、列、欄；有標籤格時也記錄標籤格座標。
- 不可寫死欄位或列號，需能解析格式不同的試算表。
錯誤與憑證
- 必須清楚回報：網址無效、沒有權限、找不到表頭、0 題、題號重複。
- 權限錯誤需同時顯示應共享給服務帳號的 email。
- Google 服務帳號憑證存放於 repo 之外，透過環境變數指定；不得提交到 repo。
